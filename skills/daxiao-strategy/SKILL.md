# 李大霄策略体系 Skill

## 定位

把李大霄的视频观点转译为**可执行的投资决策**:观点 → 定性 → 操作。
他的观点是"定性工具",不是量化信号;最终决策必须配合技术面验证(如 etf-radar)。

## 核心认知(必须先懂)

1. **他是"价值投资+防御"派**:不预测点位,强调低估、好股、余钱、量力而为
2. **反话机制**:"XX不是推荐"往往是隐性强推;报跌幅"不是推荐"才是真风险提示
3. **量能是一票否决项**:"没量=不是反转"——缩量行情里一切上涨都按"反弹"处理
4. **他有滞后性**:转折日(如2026-08-13标普7816.70)是事后命名,操作必须领先他

## 五级宏观定调(逐级防御递增/递减)

| 级别 | 关键词 | 操作含义 |
|---|---|---|
| A 高度警惕泡沫爆破 | "警惕""高度警惕""黑五类" | 全面防御,减仓高估值,现金为王 |
| B 谨慎防御/调整 | "防御""缩量等待方向" | 不加仓,防御仓持有,别接刀 |
| C 缩量温柔市/止跌 | "温柔市""缩量企稳""静观其变" | 震荡,持仓不动,等放量 |
| D 反弹(非反转) | "反弹""没量=不是反转" | 反弹可吃,撤退要有纪律(到线就减) |
| E 结构性看多 | "中流砥柱""恒指还是强的" | 保持防御配置,不追高,低吸不追 |

## 老登 vs 小登(风格理论核心)

- **老登** = 低估价值蓝筹:银行、保险、红利、央企、港股大金融
- **小登** = 高估成长题材:科技、半导体、AI、机器人、新股、概念股
- **循环定理**:"割老登追小登 → 小登山顶滚落 → 老登开始恢复 → 割小登追老登 → 以至无穷"
- **应用**:先判断循环在哪个阶段 → 决定持仓偏向
  - 小登被追捧、老登被嘲笑 → 老登吸引回升期(用户应已上车,加仓窗口)
  - 人人晒银行账户 → 老登拥挤期,该警惕
- **红线**:老登也不能追高("一块钱的东西五毛钱买才是价值投资,六十块买则得不偿失")

## 量价铁律(与大霄"没量"框架配套)

1. **地量地价三条件**(全部满足才算):
   - 量分位 ≤10-15%(近5日均量 vs 250日)
   - 20日振幅 ≤6-9%(L型躺平)
   - 距真实前低 ≤2%(注意:前低要拉250根K线找,不能只看近两周!)
2. **缩量≠地量**:爆量回落(量分位50-80%)不是地量,是"还在打,只是没那么猛"
3. **放量突破(≥近期峰值)才谈反转**;缩量碰压力位=假突破概率85%
4. **连涨之后的高位放量 = 风险**

## 当日研判流程(与 lidaxiao-monitor 联动)

1. 拉取最新报告:`docs/reports/latest.md`(检测→下载→OCR→AI分析产物)
2. 读"今日摘要"+《暗示提取》,按五级表定格(定级依据:情绪词+数据点名率)
3. 逐条对照话术解码表,标出本次视频的暗语
4. 检查当前持仓/候选股票与定级的匹配度(追高?接刀?仓位?)
5. 输出:定性 + 逐仓动作(不动/减/加) + 风险清单

## 输出格式

```
【定性】<五级之一> + 一句话依据
【大霄原话】关键引用 → 解码
【持仓映射】逐仓:动作+理由
【风险】至少一条
【免责】个人分析参考,不构成投资建议
```

## 注意事项

- 大霄观点有时滞,转折后他才命名;操作要领先,不可等他"实锤"
- 报告数据一律以项目监控产出为准,不凭记忆编造
- 多视频观点连续性:级别升降(如温柔市→警惕)代表情绪升级,需特别标注
- 无历史对比的新词(如"老登小登"首次出现)单独记录,作为后续基准
